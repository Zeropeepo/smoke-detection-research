# Smoke Detection Research

Repository for reproducing fire/smoke object-detection results and evaluating domain shift toward Indonesian wildfire scenes.

## Start here

- [Fire 2025 reproduction](Fire2025_Reproduction/README.md): paper setup, HPC runner, experiment matrix, and validation notes.
- [Indonesian domain-shift study](Domain_Shift_Indonesia/README.md): the four-model source-only and supervised-adaptation workflow, notebooks, and interpretation limits.
- [Python notebook mirrors and experiment scripts](scripts/notebooks/README.md).

Datasets, model checkpoints, and locally collected media are not included in this repository.
