# Python mirrors of notebooks

Files here are `.py` source mirrors in Jupytext-style percent format; the `.ipynb` files under each project folder remain the canonical notebook documents. They are kept side-by-side by project so local experiments can import/run notebook logic without copying outputs.

- `Domain_Shift_Indonesia/`: two Indonesian domain-shift/error-analysis notebooks.
- `Fire2025_Reproduction/`: reproduction notebook and its Kaggle experiment notebooks.

These files are intentional source mirrors, not duplicate datasets or run outputs.
